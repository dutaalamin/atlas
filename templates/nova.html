Questions

Which languages does Nova support?

First-class support for TypeScript, Python, Go, Rust and Java, with solid coverage across the rest. It works on any repo with a test command.

Can I bring my own model?

Yes. Connect an API key from any supported provider, or run a local model. Nova routes each task to the model you choose.

Where does my code go?

Nowhere it shouldn't. Code is processed in an isolated sandbox, never used for training, and you can self-host the runner.

Is there a free plan?

Yes, solo developers get a generous free tier. Teams start on a per-seat plan with shared context and audit logs.
